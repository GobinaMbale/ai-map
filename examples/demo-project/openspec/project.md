# Contexte projet

Application de facturation multi-locataire. Deux capacités spécifiées :
`user-auth` (authentification et sessions) et `billing` (facturation).

## Conventions OpenSpec

- Un change par évolution fonctionnelle, archivé une fois appliqué.
- Les deltas de spécification vivent dans `changes/<id>/specs/<capacité>/spec.md`.
- L'implémentation ne démarre qu'après validation de la proposal.
