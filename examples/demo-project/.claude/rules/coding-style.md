# Style de code

Conventions appliquées par les agents comme par les humains.

## Nommage

Les modules sont en kebab-case. Les fonctions exportées sont documentées.

## Erreurs

Toute erreur remontée à l'utilisateur doit être actionnable : dire quoi faire,
pas seulement ce qui a échoué.

## Tests

Toute correction embarque le test qui échouait avant elle.
